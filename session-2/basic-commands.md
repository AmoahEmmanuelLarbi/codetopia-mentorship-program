# Command used to initialize a repository
The command used to initialize a Git repository is:
- git init

# Right commit messages when committing
A good commit message should clearly explain the changes made. It should be short, meaningful, and easy to understand. Most
commit must use the conventional comiits format "type: shore description (under 72 chars)"

Example: git commit -m "docs: project structure setup"

# Command to check all commits
The command used to view all commits is:
- git log
- git log --oneline

# Most personally used command in Git and CLI
One of my most used Git commands is:
- git status, because it helps me quickly check changed, staged, and untracked files.
One commonly used command in CLI is cd

# The 3 stages of Git
The 3 Git states are the Working Directory, Staging Area, and Repository. The working directory is 
where I make changes to files, the staging area is where I prepare changes before saving them, and 
the repository is where Git permanently stores the project history.

# Why is Git useful?
Git is useful because it helps developers track changes in their projects, work 
with others easily, and return to older versions of files if something goes wrong. It also makes 
managing projects safer and more organized.

# Why do commit messages matter?
Commit messages matter because they explain what changes were made in 
a project. Good commit messages make it easier to understand the project history and help developers 
know what was updated, fixed, or added.
